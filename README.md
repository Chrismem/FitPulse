# FitPulse

Hey! 

FitPulse is a tracking app designed to unite fitness communities and support individuals striving for a healthier lifestyle.

This app is built for:
- Fitness seekers
- Habit builders
- Community lovers

Our goal is to help users locate nearby fitness centers, connect with like-minded communities, and track daily habits. 

We hope you enjoy exploring the application. Thanks!

Our current and planned features include:
- Smart Location Finder
- List of fitness communities
- Habit trackers (personalized)

To install the app:

1. Clone the repository:
   ```bash
   git clone https://github.com/Chrismem/FitPulse
   ```

2. Navigate to the project directory:
   ```bash
   cd FitPulse
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:
   ```bash
   python main.py
   ```
